# Smart College Portal 🎓

A web-based college management system developed using PHP, MySQL, HTML, CSS, and JavaScript.

## 📌 About the Project

Smart College Portal is a database-connected academic management system designed to connect students and college administration through one digital platform.

The system allows students to access their academic information while administrators can manage important college records.

## ✨ Student Features

- Student Login
- Student Dashboard
- My Profile
- Courses
- Attendance
- Results
- Fees
- Announcements
- Assignments
- Reports & Analytics

## 🛠️ Administrator Features

- Manage Students
- Manage Courses
- Manage Teachers
- Manage Academic Records
- Manage Fees
- Manage Announcements
- Manage Assignments
- Manage Attendance
- Teacher GPA Calculator
- SGPA Calculator
- CGPA Calculator
- Reports & Analytics

## 📊 Reports & Analytics

The system provides:

- Total Students
- Total Courses
- Total Results
- Average Marks
- Top Students
- Course-wise Performance
- Student Performance
- Grade Distribution
- Semester Performance

The project uses:

## 🚀 Local Setup

1. Install XAMPP.
2. Place the project folder inside:

`C:\xampp\htdocs\`

3. Create the MySQL database.
4. Import the database tables.
5. Configure the local database connection.
6. Start Apache and MySQL from XAMPP.
7. Open the project through localhost.

Developed as a practical academic project demonstrating web development, database management, authentication, and data analytics.
